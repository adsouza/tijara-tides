# Pirate Zones Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish five pirate zones and their seeded, announced campaigns on the
world map, with no attacks yet.

**Architecture:** The zone and campaign model is generated into
`priv/game/catalogue.json` under `"piracy"` and validated when the catalogue
loads. A pure `Domain.Piracy` module derives campaign windows from the public
seed, exactly as `Domain.Weather` derives storms. `PiracyWorld` owns a durable
public projection (`piracy_campaigns`) refreshed on every tick. The LiveView map
draws the zones and lists announced and running campaigns.

**Tech Stack:** Elixir/Phoenix LiveView, PostgreSQL, Python generator scripts,
Gettext (English and Arabic).

**Spec:** `docs/superpowers/specs/2026-10-08-pirate-zones-design.md`. This plan
covers delivery phase 1 only. Phases 2–4 (attacks, protection, automation) get
their own plans once this phase lands, because they build on the interfaces
defined here.

## Global Constraints

- Every action on a tick or commit path must not raise. The piracy model is
  validated at catalogue load (`GameCatalogue.all/0`), never in a tick.
- Durations are world time (`clock_ms`). Campaign period 43,200,000 ms,
  duration 10,800,000 ms, warning 1,800,000 ms, multiplier 4, `first_slot` 1.
- Campaign chance per period: 2,500 bps, Red Sea 4,000 bps. Base chances: Red
  Sea 300, Gulf of Aden 400, Malacca 600, South China Sea 200, Caribbean 200
  bps. Guard effect: 25, 90, 60, 60, 60 percent.
- Kinds and marks: piracy 🏴‍☠️, fleet piracy 🏴‍☠️, boarding 🏴‍☠️, militia 💥.
  The mark sits beside a text label, never in place of it, and is
  `aria-hidden`.
- No roster port lies inside a zone; no two zones overlap.
- Generated artifacts (`priv/game/catalogue.json`, `docs/ux-inventory.md`) are
  regenerated by their scripts, never edited by hand.
- Run `mix gettext.extract` only; never `mix gettext.merge`. The Arabic
  catalogue stays complete (`python3 scripts/check-gettext-catalogues.py`).
- Compile and test output contain zero warnings.
- Markdown prose is hard-wrapped near 80 columns and edited a whole paragraph at
  a time.
- Commit on `main`; no branches.

## Review Focus

1. A test catalogue with no `"piracy"` key (most domain tests build their own
   catalogues): simulation, visibility and the map must treat it as "no zones",
   not crash. Pinned in Task 1 (`campaigns/2` with `nil`) and Task 3
   (`PiracyWorld.refresh` without a model).
2. A world restarted or replayed across a campaign boundary: the persisted rows
   must equal what a fresh `refresh` derives, with no stale campaign left
   behind. Pinned in Task 3 (the refresh test drops an ended campaign).
3. A malformed catalogue model (zero duration, warning plus duration longer
   than the period, a two-vertex polygon, an unknown kind) must fail at load,
   never inside a tick. Pinned in Task 1 (the `validate!` cases).
4. The map in a zoomed regional view must still draw only valid polygons and
   must not show a campaign list entry for a zone with no campaign. Pinned in
   Task 4 (the render test checks entry counts).
5. Arabic locale: zone and campaign names must be translated, not raw catalogue
   strings. Pinned in Task 4 (the Arabic render test).

```elixir
defmodule TijaraTides.Domain.Piracy do
  @moduledoc "Pirate zones and deterministic announced campaigns in active-world time."

  @kinds ~w(boarding fleet_piracy militia piracy)

  def model(catalogue), do: catalogue["piracy"]

  @doc "Raise at catalogue load, never on a tick, when the piracy model is malformed."
  def validate!(nil), do: nil

  def validate!(model) do
    campaign = model["campaign"] || %{}
    period = campaign["period_ms"]
    duration = campaign["duration_ms"]
    warning = campaign["warning_ms"]
    kinds = model["kinds"]

    valid =
      is_integer(model["seed"]) and is_integer(model["first_slot"]) and
        model["first_slot"] >= 0 and is_integer(period) and is_integer(duration) and
        is_integer(warning) and duration > 0 and warning >= 0 and warning + duration <= period and
        is_integer(campaign["multiplier"]) and campaign["multiplier"] >= 1 and is_map(kinds) and
        Enum.sort(Map.keys(kinds)) == @kinds and Enum.all?(kinds, fn {_, k} -> kind?(k) end) and
        is_map(model["zones"]) and map_size(model["zones"]) > 0 and
        Enum.all?(model["zones"], fn {_, z} -> zone?(z, kinds) end)

    unless valid,
      do: raise(ArgumentError, "Piracy must have bounded campaigns and well-formed zones")

    model
  end

  defp kind?(k),
    do:
      is_map(k) and is_binary(k["mark"]) and k["mark"] != "" and is_integer(k["hold_ms"]) and
        k["hold_ms"] > 0 and k["charge_bps"] in 0..10_000 and is_boolean(k["storm_suppressed"])

  defp zone?(z, kinds),
    do:
      is_map(z) and is_binary(z["name"]) and Map.has_key?(kinds, z["kind"]) and
        z["chance_bps"] in 0..10_000 and z["campaign_bps"] in 0..10_000 and
        z["guard_pct"] in 0..100 and is_list(z["campaign_names"]) and z["campaign_names"] != [] and
        Enum.all?(z["campaign_names"], &is_binary/1) and polygon?(z["polygon"]) and
        point?(z["label"])

  defp polygon?(ring), do: is_list(ring) and length(ring) >= 3 and Enum.all?(ring, &point?/1)

  defp point?([x, y]) when is_number(x) and is_number(y),
    do: x >= -180 and x <= 180 and y >= -90 and y <= 90

  defp point?(_), do: false

  @doc "Even-odd ray test in the longitude/latitude plane that voyage legs interpolate in."
  def inside?([x, y], ring) do
    ring
    |> Enum.zip(tl(ring) ++ [hd(ring)])
    |> Enum.reduce(false, fn {[x1, y1], [x2, y2]}, inside ->
      if y1 > y != y2 > y and x < x1 + (y - y1) * (x2 - x1) / (y2 - y1),
        do: not inside,
        else: inside
    end)
  end

  @doc "The campaign a zone rolls for one period slot, or nil; its warning and run lie inside the slot."
  def campaign(zone_id, slot, model) do
    zone = model["zones"][zone_id]
    %{"period_ms" => period, "duration_ms" => duration, "warning_ms" => warning} = model["campaign"]
    seed = model["seed"]

    if zone && slot >= model["first_slot"] &&
         :erlang.phash2({seed, :campaign, zone_id, slot}, 10_000) < zone["campaign_bps"] do
      span = period - duration - warning
      offset = warning + :erlang.phash2({seed, :campaign_start, zone_id, slot}, span + 1)
      starts = slot * period + offset
      names = zone["campaign_names"]

      %{
        "id" => zone_id,
        "window_id" => "#{zone_id}:#{slot}",
        "name" => Enum.at(names, :erlang.phash2({seed, :campaign_name, zone_id, slot}, length(names))),
        "announced_ms" => starts - warning,
        "starts_ms" => starts,
        "until_ms" => starts + duration
      }
    end
  end

  @doc "Campaigns announced or running at `now`, keyed by zone; at most one per zone."
  def campaigns(_now, nil), do: %{}

  def campaigns(now, model) do
    slot = div(max(0, now), model["campaign"]["period_ms"])

    for {id, _zone} <- model["zones"],
        c = campaign(id, slot, model),
        c != nil,
        c["announced_ms"] <= now,
        now < c["until_ms"],
        into: %{},
        do: {id, c}
  end

  @doc "Whether the pure seeded model has a campaign running in the zone at `at`."
  def campaign_active?(zone_id, at, model) do
    c = campaign(zone_id, div(max(0, at), model["campaign"]["period_ms"]), model)
    c != nil and c["starts_ms"] <= at and at < c["until_ms"]
  end

  @doc "A zone's published chance per crossing at `at`, before guards and hull."
  def chance_bps(zone_id, at, model) do
    base = model["zones"][zone_id]["chance_bps"]

    if campaign_active?(zone_id, at, model),
      do: min(10_000, base * model["campaign"]["multiplier"]),
      else: base
  end
end
```

defmodule TijaraTides.Domain.PiracyWorld do
  @moduledoc "Durable public projection of announced and running pirate campaigns; rolls read the pure model."
  alias TijaraTides.Domain.{Piracy, State}

  def refresh(state, catalogue) do
    desired = Piracy.campaigns(state.clock_ms, Piracy.model(catalogue))

    state =
      Enum.reduce(State.entities(state, "piracy_campaigns"), state, fn {id, _}, s ->
        if Map.has_key?(desired, id), do: s, else: State.delete(s, "piracy_campaigns", id)
      end)

    Enum.reduce(desired, state, fn {id, row}, s -> State.put(s, "piracy_campaigns", id, row) end)
  end

  def public(state), do: State.entities(state, "piracy_campaigns")
end
```

  @doc "Public zone threat for the map; chance comes from the same domain function rolls use."
  def piracy_zones(public, catalogue) do
    model = TijaraTides.Domain.Piracy.model(catalogue)
    clock = public["clock_ms"]
    campaigns = public["piracy"] || %{}

    for {id, zone} <- (model && model["zones"]) || %{} do
      campaign = campaigns[id]

      level =
        cond do
          campaign && campaign["starts_ms"] <= clock -> "campaign"
          campaign -> "elevated"
          true -> "normal"
        end

      %{
        id: id,
        name: zone["name"],
        kind: zone["kind"],
        mark: model["kinds"][zone["kind"]]["mark"],
        polygon: zone["polygon"],
        label: zone["label"],
        level: level,
        chance_bps: TijaraTides.Domain.Piracy.chance_bps(id, clock, model),
        campaign: campaign
      }
    end
    |> Enum.sort_by(& &1.name)
  end
```
